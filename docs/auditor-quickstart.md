# Auditor quickstart: verify a Raucle evidence pack, offline, in five minutes

*Status: P1.7c. One page. Written for an auditor who has never seen the
system, handed a `audit-pack.zip` (and the verifier script) by the operator.*

## What you have

- `audit-pack.zip`: the operator's export pack: receipts, the pinned key
  snapshot, signature bundle, timestamp and policy slots, a claim sheet,
  and a manifest.
- `verify_pack.py`: the standalone verifier. It is a single file needing
  only Python 3.11+ and the `cryptography` package. It contains no raucle
  code, no credentials, and no network dependency.

## Zero-dependency offline verification

1. Install the verifier's only dependency, if you do not have it:
   `pip install cryptography`.
2. Unpack the zip: `unzip audit-pack.zip` (creates `audit-pack/`).
3. Run: `python verify_pack.py audit-pack/`
4. Read the verdict. **GREEN**: every manifest digest matched and every
   receipt verified against the embedded key snapshot. **AMBER**: all
   cryptography passed but a warning was raised, such as a missing claim
   sheet guard: ask the operator to explain each warning. **RED**: the
   verifier names the exact file or receipt that failed. Exit code 0 is
   green, 1 is red.

No internet connection is used, wanted, or trusted at any step. The pack
carries the public key snapshot it is checked against, so verification
depends on nothing outside the unpacked directory. You never contact the
operator's system, and nothing from your machine is shared.

## Reading the claim sheet

`claims.md` inside the pack was generated by the pack builder itself and
states only what the pack contains and what you can check with it. It ends
with a mandatory no-claim guard: the pack proves integrity and authority
within trust policy `evd-trust-1`, and nothing beyond that; it asserts
no compliance, certification, approval, accreditation, attestation or
warranty of any kind. Where the pack cannot prove something (no
timestamp tokens, no policy coverage, a pending chain-graph slot, the
bounded query window): the sheet says so explicitly. Absences are
statements, and they are stated, not papered over.

If `claims.md` is missing its guard, the verifier raises a prominent
warning: the guard header line `## Mandatory no-claim guard` and its
sentinel sentence must both be present. Do not accept a pack whose claim
sheet has been edited: the manifest will not match anyway.

## Reproducing the claim sheet

Anyone can re-render the claim sheet from the raw inputs with:

    python scripts/render_claim_sheet.py \
      --evidence-store <operator's evidence store JSONL> \
      --trust-roots <operator's trust-root snapshot> \
      --from 2026-11-01 --to 2026-12-01

The output is the generated sheet's text for that window; the guard is
re-checked before it prints. The full build (with files and hashes) is
`python scripts/build_audit_pack.py ... --out <dir>`; see
`docs/audit-pack.md` for the complete pack documentation.
